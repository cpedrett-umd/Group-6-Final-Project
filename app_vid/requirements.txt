# Native window for desktop.py. Platform backends install automatically:

# Image decoding in ocr.py. RapidOCR pulls it in too, but ocr.py imports it
# directly, so it is declared rather than relied on transitively.

# Repairs OCR lines whose spaces collapsed ("70%offbeforethesupplementban").
